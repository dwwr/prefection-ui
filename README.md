# prefection-ui

UI Elements inspired by Shynola Films' interpretation of the Hitchhiker's Guide in the 2005 film.

## Getting started

```bash
npm install
npm run dev
```

The Vite app runs at [http://localhost:5173](http://localhost:5173).

```bash
npm run storybook
```

Storybook runs at [http://localhost:6006](http://localhost:6006).

## Tech stack

- React 19 + TypeScript
- Vite 8
- Emotion (`@emotion/react`)
- Storybook 10
